**What is Linting?**
Linting is Process of running a program that static analysis (without running/compiling) your code for potential errors / Flag code construct that are suspicious / extremely likely to be bug (code will run, but in the long run can cause you harm (make things more complicated)) $\xrightarrow{\text{help}}$ display error before execution
	* Check [PEP8](https://peps.python.org/pep-0008/) for Python Conventions
	* Check [PyLint Documentation](https://pylint.readthedocs.io/en/latest/user_guide/checkers/features.html#basic-checker-messages) to see use-case examples of linter
