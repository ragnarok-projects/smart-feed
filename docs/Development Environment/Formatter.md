**What is a Formatting within code?**
Making source code readable for others, structure and layout your code which result to your code be visually appealing and have consistency
**What is Code Formatter?**
Code Formatter is a tool/program which will automatically format your code base on predefined style guidelines and conventions and even your team rules.
**What it do?**
consistent indentation, spacing, line breaks, etc.
**Why use it?**
* Consistency
* Readability
* Reduce Human Error
* Code Reviews
* Enforce Coding Standards
* Productivity
* Collaboration
* Integration
